# 온전히 — 나의 집중 기록

React · TypeScript · CSS로 만든 브라우저 전용 집중 기록 웹앱입니다. 초기 기록은 비어 있습니다.

## 실행

Node.js 20 이상에서 이 폴더를 터미널로 열고 실행하세요.

```sh
npm install
npm run dev
```

표시되는 http://127.0.0.1:5173 주소로 접속하세요. 개발 서버는 파일 제공만 담당하며 계정이나 데이터 서버는 사용하지 않습니다.

```sh
npm test
npm run build
```

빌드 결과는 dist 폴더에 생성됩니다. localStorage와 Web Locks를 사용할 수 있는 최신 브라우저의 localhost 또는 HTTPS에서 실행하세요. 여러 탭 중 첫 탭만 기록을 관리하며, 그 탭을 닫은 뒤 다른 탭을 새로고침하면 관리 권한을 가져옵니다.

## 기록 동작

- visibilitychange로 페이지가 숨겨지면 집중 구간을 닫고 이탈 1회를 기록합니다.
- 복귀 시 버튼을 눌러야 이어집니다. 수동 휴식은 이탈 횟수에 포함하지 않습니다.
- 1초마다 체크포인트를 저장하며 새로고침 시 마지막 저장 시점까지만 복구합니다.
- 구간별 시각 차이로 계산하고 사용자 현지 자정을 기준으로 날짜별 시간을 나눕니다.
- 데이터는 해당 브라우저와 사이트 주소에 귀속되며 브라우저 데이터 삭제 시 함께 삭제됩니다.
- 실제 집중 여부, 다른 기기의 사용, 페이지가 계속 보이는 상태의 창 전환은 판단하지 않습니다.

## 검증

자동 테스트: 이탈 후 시간 제외, 이탈 중복 방지, 수동 휴식, 체크포인트 복구, 종료 멱등성, 현지 자정 분리.
브라우저 확인: 준비 → 다짐 → 시작 → 다른 탭 → 복귀 → 다시 집중 → 종료. 수동 휴식 중 이동 시 횟수가 늘지 않는지, 실행 중 새로고침 후 정지 상태인지 확인하세요.
